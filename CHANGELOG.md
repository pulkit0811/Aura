# Changelog

All meaningful user-facing and architectural changes to AURA are recorded here.

## Unreleased

### Added

- Initial AURA project documentation and architecture baseline.
- Repository-wide environment, formatting, testing, and ignore configuration.
- FastAPI backend foundation with health monitoring and normalized API errors.
- Next.js frontend foundation with a typed backend API client.
- Responsive AURA application shell with workspace navigation and Overview screen.
- Local frontend-to-backend verification with development CORS support for both local host aliases.
- Frontend dependency lockfile and patched Next.js `15.5.9` release.
- Shared design tokens and reusable UI primitives for panels, buttons, and status badges.
- Functional navigation routes and honest scaffold screens for the planned AURA modules.
- Reusable loading, empty, and error states with backend retry feedback.
- Initial Overview dashboard with live system status, workspace context, empty activity states, and quick actions.
